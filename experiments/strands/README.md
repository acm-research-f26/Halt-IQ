# Strands input sensitivity

This checks whether the existing native decision model responds to a changed answer: two handcrafted facts, each paired with a correct and contradictory draft, with labels kept outside model inputs. The four cases are fixed in `../../configs/strands/input-probe.json`; `../../scripts/probe_strands_inputs.py` computes one frozen encoder representation per case and scores both the released and previously trained heads using their separately fitted confidence temperatures. The CSV contains eight real head scores; the summary counts four physical encoder forwards and records an earlier interrupted startup separately. These are two simple facts, not a HotpotQA or Tau2 performance estimate, a fine-tuning gain, or a measurement of live orchestration quality. Startup, encoding, head scoring, idle and wall timings overlap and must not be added. Native reproduction requires the external local model snapshots and the resource/ownership checks enforced by the probe script.
